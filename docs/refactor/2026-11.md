## 見送ったこと

| 内容 | 理由 |
| --- | --- |
| `judge/runner/`の小さな重複（ジャッジコードのランタイムの検査が2か所、役割名の式が3か所、上限の直書き） | runnerのファイルはdigestに入るので、コメント1行の変更でも実配布が要る。次にrunnerを変える配布に合わせる |
| `rollout.py`と`verify.py`にある、ホストの準備確認スクリプトの4つの写し | 重要な挙動を本番のAWSなしでは確かめられない |
| 言語ごとのsmokeの断片が、Pythonの表と`language-smoke.json`の2か所にある | 移すと実機のsmokeが変わる |
| コンテストのページから順位表を部品に分ける | 順位表の取得はページの更新の最初の手順で、参加登録の後にも呼ばれる。部品へ移すと取得の時機が変わり、表示だけの部品にするとpropsが10個を超える |
| `<details>`のメニュー3つの開閉の共有 | 3つの処理が同じではない |
| CLIのジャッジの種類の一覧の共有 | 種類を足すときは構造体の欄も要るので、減る手間が小さい |
| CIのPostgreSQLの起動と待ち、Terraformの準備の共有 | GitHub上でしか確かめられない |
| httpapiのテストの下準備の改名と共有 | 新しいテストは既に共通の下準備を使っている |
| `.visually-hidden`の写し、グローバルCSSの上書きされている規則 | 宣言が少しずつ違い、見た目の比較が要る |

調査中に見つけた不具合の疑いと、仕様の判断が要る点は、直さずに別に記録した。
