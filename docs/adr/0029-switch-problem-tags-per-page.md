# ADR 0029: 問題のタグの表示をページごとに切り替え、設定の「表示」タブをなくす

- 状態：Accepted
- 決定日：2026-10-24
- 範囲：問題のタグを表示に切り替える場所と、選んだ表示の保存
- 一部変更：[ADR 0018](0018-tag-problems-and-posts.md)の、問題のタグの表示を設定の「表示」タブで選び、Cookieに保存する決定。[ADR 0026](0026-switch-problem-tags-on-problem-list.md)の、問題一覧のスイッチが設定と同じCookieを切り替え、問題ページには切り替えを置かないとした決定

## 背景

ADR 0026までは、問題のタグを表示するかをブラウザーに1つだけ保存していた。
問題一覧でタグを見るためにオンにすると、そのあと開く問題ページでもタグが出る。
問題ページで消すには、問題一覧か設定画面へ移る必要があった。

## 決定

### 問題一覧と問題ページに、それぞれスイッチを置く

問題一覧と問題ページに「タグを表示」のスイッチを置く。スイッチはそのページのタグだけを切り替え、ほかのページには反映しない。
問題ページのスイッチは、タグが付いた問題にだけ出す。
オフのときは、どちらのページでもスイッチの横に「解法のヒントになることがあります。」と添える。

### 選んだ表示を保存しない

ページを開くたびにオフから始める。
同じページの中では保つ。問題一覧はページ送りで、問題ページは問題文・解説・提出のタブを移っても変わらない。
タグで絞り込んだ一覧は別のページとして扱い、オフから始める。

サーバーは常にタグを伏せて描画するので、読み込み直後にタグが一瞬見えることはない。

### 設定の「表示」タブをなくす

タブには問題のタグの設定しかなかったため、タブごと削除する。

### 変えないこと

- 初期値は表示しない。
- 未ログインでも切り替えられる。
- 問題一覧の検索欄は、スイッチがオンのときと、タグで絞り込んだ一覧にだけ出す。
- 定期便とコンテストの開催中は、問題のタグを返さない。

## 代替案

- **設定を残し、ページのスイッチで一時的に上書きする**：タグを見たい人は毎回オンにしなくて済むが、表示を決める場所が2か所に分かれ、どちらが効いているか分かりにくい。
- **問題ページだけ保存せず、問題一覧は設定に従う**：一覧でタグを探す人には便利だが、ページによって切り替えの効き方が違う。

## 影響

- タグを見たい人は、ページを開くたびにスイッチをオンにする。
- ADR 0026で採らなかった、問題ページでの切り替えを置く。
- Cookie`openoj-problem-tags`は読まなくなる。すでに保存されたものは、最長1年で期限が切れる。
- `/my/settings?tab=display`は「プロフィール」タブを開く。
