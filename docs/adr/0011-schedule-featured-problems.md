# ADR 0011: 月曜と木曜に難易度別の問題を出す

- 状態: Accepted
- 決定日: 2026-09-26
- 範囲: 定期出題の募集、選出、公開と解説の解禁。実装は未着手

## 背景

現在の問題投稿は、保存した下書きを作者が操作した時点で公開する。
定期的に解くきっかけを作るには、完成した問題を公開前に預かり、決まった時刻に出題する仕組みが必要になる。
一方、毎日新作を出す運用には継続的な応募と確認が必要であり、開始時点では問題の在庫を保証できない。

## 決定

### 出題日時と難易度

定期出題は日本時間の毎週月曜と木曜の23時に行う。
各回に**Easy枠**と**Hard枠**を一問ずつ設け、合計二問を出す。
Easy枠はLv.1〜4、Hard枠はLv.5〜10とする。
この境界は既存の難易度ガイドでLv.4が緑、Lv.5が水に相当することに合わせる。

枠の判定には作問者が設定した難易度を使う。
公開後に集まる難易度投票によって、掲載済みの枠を変更しない。
Hard枠にLv.9またはLv.10の問題が選ばれたときは、表示名を**Ultimate**にする。
UltimateはHard枠の特別な表示であり、第三の出題枠にはしない。
該当する問題が出るまで、募集画面でUltimateを別枠として案内しない。

### 新作の応募と選出

作者は保存した未公開問題を、完成後に定期出題へ応募できる。
応募時には難易度と解説を必須とし、公開可能な問題であることを確認する。
応募した問題は選出まで非公開とし、作者とテスターは従来どおり確認できる。
通常の即時公開も選べるが、公開済みの問題は新作の応募対象から外す。
コンテストに登録された未公開問題も、定期出題の応募対象から外す。
作者が応募を取り下げるか通常公開した場合は、選出対象から外す。

応募時に作者は「早めに出したい」と「あとからでもよい」のいずれかを選ぶ。
選出では前者を優先しつつ、後者が無期限に待ち続けないよう両方から選ぶ。
選出の重みと同じ作者の応募数の上限は、応募状況を見て実装時に定める。
応募後に内容が変わった問題は、選出前に公開条件と難易度を再確認する。

### 在庫がない場合

ある難易度枠に選出できる新作がなければ、その枠には公開済み問題を無作為に選んで**復刻**として掲載する。
復刻候補は同じ難易度枠から選び、開催中のコンテスト問題を除く。
直近に掲載した問題は避け、他に候補がなければ除外期間を緩める。
復刻では解説と他者の提出を再び隠さず、「解説公開済み」と表示する。
新作も復刻候補もない場合は、その枠を欠番として表示し、別の難易度の問題で埋めない。

### 新作の解説と提出の公開

新作は出題日の23時に問題文と提出受付を公開し、翌日の22時まで解説と他者の提出一覧および提出詳細を伏せる。
この期間も、提出者は自分の提出と採点結果を確認できる。
翌22時以降は解説と他者の提出を公開し、過去の出題からも閲覧できるようにする。
解禁は画面表示だけでなく、公開APIと認証済みAPIの応答にも適用する。
共有時には解禁前の感想に解法のネタバレを含めないよう案内する。

## 代替案

毎日二問を出す案は、週に十四問の候補を要し、開始時点で新作の応募数を見込めないため採用しない。
新作だけで枠を埋める案は、応募が途切れると定期出題も止まるため採用しない。
復刻問題を再び非公開扱いにする案は、解説と提出がすでに閲覧された後では解法を隠せないため採用しない。

## 影響と未決事項

未公開問題の応募状態、優先希望、各回の選出結果と解禁時刻を永続化する必要がある。
出題処理は同じ枠へ二問を割り当てないようにし、再実行しても掲載結果を変えない。
現行の公開問題APIは解説を返し、提出APIは他者の提出を返すため、出題後の時刻に応じたアクセス制御を追加する。
コンテスト終了まで解説と提出を伏せる既存の制御を参考にする。

応募の確認方法、直近掲載の除外期間、優先希望の配分、時刻どおりに出題できなかった場合の扱いは実装時に決める。
