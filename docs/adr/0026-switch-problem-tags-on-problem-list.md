# ADR 0026: 問題のタグを問題一覧で表示に切り替えられるようにする

- 状態：Accepted
- 決定日：2026-10-18
- 範囲：問題のタグを表示する設定の切り替え場所、未ログインの閲覧者の扱い
- 一部変更：[ADR 0018](0018-tag-problems-and-posts.md)の、問題のタグの表示を設定の「表示」タブだけで切り替え、未ログインでは初期値のまま表示しないとした決定

## 背景

ADR 0018では、問題のタグを表示する設定を設定画面の「表示」タブだけに置いた。
初期値は表示しないで、問題一覧のタグ検索欄も設定がオンのときだけ出る。
そのため設定を開かない閲覧者には、問題一覧にタグ機能があることが分からない。実際に、タグ機能はあまり知られていない。

未ログインでは設定画面を開けないので、タグを表示する手段がなかった。
設定はブラウザーのCookieに保存するので、切り替えにログインは要らない。

## 決定

### 問題一覧に、同じ設定を切り替えるスイッチを置く

問題一覧の表の上に「タグを表示」のスイッチを置く。設定の「表示」タブと同じCookieを切り替えるので、どちらで変えても両方に反映する。
オフのときは、スイッチの横に「解法のヒントになることがあります。」と添える。オンにすると一覧のすべての問題のタグが一度に見えるため、押す前に分かるようにする。
オンにするとタグ検索欄も出る。スイッチを検索欄の前に置き、検索欄が出てもスイッチの位置が変わらないようにする。

### 未ログインでも切り替えられる

問題一覧のスイッチは、ログインしていなくても使える。
選んだ表示はブラウザーに残り、ログインの有無に関係なく問題一覧と問題ページに反映する。

### 初期値と開催中の扱いは変えない

初期値は表示しないのままとする。ネタバレを避けたい人は何もしなくてよい。
定期便とコンテストの開催中にタグを返さない決定も変えない。スイッチをオンにしても、開催中の問題のタグは出ない。

## 代替案

- **問題ページにも切り替えを置く**：これから解く問題のタグを、その場で開く操作になる。ADR 0018で採らなかった「タグを折りたたんで表示する」案とほぼ同じになるため、問題一覧だけに置く。
- **問題一覧から設定画面へ案内する**：設定の置き場所は1か所で済むが、未ログインでは開けず、ページを移る手間も残る。
- **初期値を「表示する」にする**：タグに気づかれやすいが、ADR 0018と同じ理由で採らない。ネタバレを避けたい人が切り替えを見つける前にタグを見てしまう。

## 影響

- 問題のタグを見るには、問題一覧か設定画面で表示を選ぶ。未ログインでも問題一覧から選べる。
- 設定画面の「表示」タブはそのまま残す。
