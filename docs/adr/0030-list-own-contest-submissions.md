# ADR 0030: コンテストの自分の提出を一覧にし、見られない「すべての提出」をメニューに出さない

- 状態：Accepted（狭い幅のメニューのスクロールは0031、問題ページの「すべての提出」タブは[0034](0034-list-contest-problem-submissions-in-contest.md)で一部変更）
- 決定日：2026-10-24
- 範囲：コンテストメニューの提出の項目、コンテスト全体の自分の提出の一覧、問題ページの「すべての提出」タブ、コンテストの提出一覧API
- 一部変更：[ADR 0024](0024-team-and-onsite-participation.md)の、開催中のチームのメンバーにはコンテストの提出一覧でチームの提出を出す決定（画面では「チームの提出」に移す。APIは変えない）

## 背景

コンテストメニューには、コンテスト全体の「提出一覧」しかなかった。
開催中の参加者はこの一覧を見られず、自分の提出は各問題ページの「自分の提出」で問題ごとにしか見られない。
AtCoderでは、コンテストの中の自分の提出を全問題分まとめて見られるので、それに合わせた方が直感的だという意見があった。

一方、見られない「提出一覧」は、開催中の参加者のメニューに残り、開くと「終了後に公開されます」と案内するだけだった。

## 決定

### コンテスト全体の自分の提出を一覧にする

コンテストに「自分の提出」の画面（`?view=my-submissions`）を加える。
中身は、問題ページの「自分の提出」を全問題分まとめたものとし、凍結後の自分の提出と終了後の練習提出も含める。
チーム戦では問題ページと同じく「チームの提出」と呼び、チームメイトの提出も並べる。
列、ページ送り、表示件数は「すべての提出」と同じにし、オンサイトの絞り込みは付けない。
開始前から終了後まで、ログインしていればいつでも開ける。

APIは、コンテストの提出一覧に問題ごとの一覧と同じ`mine=1`と`mine=team`を加える。
公開APIでは使えない。

### 提出の項目をAtCoderと同じくまとめる

メニューの「提出一覧」を「すべての提出」と呼び替え、「自分の提出」と2つを「提出 ▾」の中に並べる。
並びは、AtCoderと同じく「自分の提出」を上にする。

### 見られない「すべての提出」をメニューに出さない

「すべての提出」は、今の権限で見られる人にだけ出す。
終了後の全員と、開催前・開催中のスタッフ（作成者、作問者、テスター）である。
開催中のチームのメンバーにも出さない。チームの提出は「チームの提出」で見られるためである。

「すべての提出」を出さない間は、「提出 ▾」の中身が1つになるので、同じ位置に「自分の提出」を直接置く。
開催中にもっともよく使う画面なので、開く手間を省く。
問題ページの「すべての提出」タブも、同じ条件で出さない。
URLを直接開いた場合は、これまでどおり終了後に公開される旨を案内する。

## 代替案

- **メニューに「自分の提出」を1つ足す**：手数は少ないが、メニューが7つになり、スマホの幅で収まらない。
- **「提出一覧」の中で自分とすべてを切り替える**：メニューは変わらないが、AtCoderに慣れた人が自分の提出を探す場所と違う。
- **出せない間も「提出 ▾」の中身を1つにして残す**：メニューの形は変わらないが、開催中に毎回2手かかる。

## 影響

- 開催中の参加者のメニューは「概要 / 問題 / 順位表 / 自分の提出 / 解説一覧 / 質問」になり、終了後は「自分の提出」の位置が「提出 ▾」に変わる。
- 開催中のチームのメンバーは、チームの提出をコンテストの「チームの提出」で見る。APIのコンテストの提出一覧は、これまでどおり開催中のメンバーにチームの提出を返す。
- 提出詳細のパンくずは、コンテストの自分の提出から開いたときにその一覧へ戻る。
