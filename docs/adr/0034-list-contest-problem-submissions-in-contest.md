# ADR 0034: コンテストの問題ページからタブをなくし、提出一覧を問題で絞り込む

- 状態：Accepted
- 決定日：2026-10-26
- 範囲：コンテストの問題ページのタブ、コンテストの提出一覧の絞り込み、コンテストの問題名の表記、コンテストの提出一覧API
- 一部変更：[ADR 0030](0030-list-own-contest-submissions.md)の、問題ページの「すべての提出」タブを権限に応じて出す決定（タブそのものをなくす）

## 背景

コンテストの問題ページには「問題文 / 解説 / 自分の提出 / すべての提出」のタブがあった。
ADR 0030で、自分の提出と全体の提出はコンテストメニューから全問題分をまとめて見られるようになった。
問題ページのタブは、同じ一覧の問題ごとの版になり、置き場所が2つある状態だった。

解説も、コンテストメニューの「解説一覧」から各問題の解説を開ける。

## 決定

### 問題ページのタブをなくす

コンテストの問題ページは、問題文と提出欄だけにする。

解説の画面（`?view=editorial`）は残し、「解説一覧」から開く。
パンくずは「コンテスト / 解説一覧 / 問題名」とし、問題名の上に「解説」と添える。
解説の本文は「解説」の見出しで始まることが多いので、本文には見出しを足さない。

問題ページの`?view=my-submissions`と`?view=submissions`は、コンテストの同じ一覧をその問題で絞り込んだ画面へ転送する。
通知や提出詳細のパンくずなど、これまで問題ページの一覧を指していたリンクも、絞り込んだコンテストの一覧を指す。

### コンテストの提出一覧を問題で絞り込む

「自分の提出」と「すべての提出」に「問題」の選択欄を置く。
選んだ問題は`?problem=A`のように問題の記号でURLに残し、オンサイトの絞り込みと同じく1ページ目に戻す。

1問に絞り込んだ一覧では、その問題をリジャッジできる人（作者、テスター、運営）に、行を選んでリジャッジする操作を出す。
問題ページの一覧にあった操作を引き継ぐためである。

一覧の列は問題ページの一覧と同じにし、提出日時の次に問題名を加える。
問題名は問題ページへのリンクにし、提出詳細へは右端の「詳細」から移る。

APIは、コンテストの提出一覧に`problem`（問題ID）を加える。
公開APIでも使える。

### コンテストの問題名に記号を付ける

コンテストの中では、問題名を「A - 問題名」と表記する。
問題ページの見出しとパンくず、提出一覧、提出詳細、絞り込みの選択欄が対象である。
問題一覧と解説一覧は、記号の列が隣にあるので変えない。

## 代替案

- **タブを残し、コンテストの一覧にも絞り込みを足す**：入口が2つのまま残り、どちらを使うか迷う。
- **解説も問題ページから外し、解説一覧の中で読ませる**：解説一覧が長くなり、問題ごとのユーザー解説の置き場所も変える必要がある。
- **問題の絞り込みを問題IDでURLに残す**：URLが長くなり、共有されたリンクから問題が読み取れない。

## 影響

- 問題ページから自分の提出を見るには、コンテストメニューの「自分の提出」を開き、問題を選ぶ。
- 問題ページの提出一覧を指す古いURLは、絞り込んだコンテストの一覧に転送されるので、引き続き使える。
- コンテストの問題別提出一覧API（`/contests/{id}/problems/{problem}/submissions`）は、画面からは使わなくなるが、公開APIとして残す。
