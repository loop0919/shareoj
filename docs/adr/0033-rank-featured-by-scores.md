# ADR 0033: 定期便の順位を、Hardの点数、Easyの点数の順に決める

- 状態：Accepted
- 決定日：2026-10-26
- 範囲：定期便の順位表の順位、各問題の欄の表示、経過時間と不正解数の数え方、順位表のAPI
- 一部変更：
  - [ADR 0011](0011-schedule-featured-problems.md)の定期便の順位表の順位と表示（正解状況ではなく点数で順位を決め、点数を表示する）
  - [ADR 0025](0025-score-partially-with-test-groups.md)の「定期便の順位表には、ADR 0011のとおり得点を出さない」と、定期便の順位の「正解」を満点の提出とした決定（満点は、点数の比較で先に比べる条件として残す）

## 背景

定期便の順位表は、正解状況だけで順位を決めていた（ADR 0011）。
順位は「両方正解、Hardのみ正解、Easyのみ正解、0完」の順で、得点は表示しない。
部分点を入れたとき（ADR 0025）、定期便では1つの提出で満点に届いたときだけを正解とし、満点に届かない提出は不正解に数えることにした。

この規則では、部分点の問題が定期便に出ても、満点に届かなかった参加者の間で取った点数の差が順位に表れない。
Hardで99点を取った参加者も0点の参加者も、0完として同じ順位に並ぶ。

## 決定

### 順位をHardの点数、Easyの点数の順に決める

参加者の順位は、Hardの点数が高い順に決め、Hardが同点ならEasyの点数が高い順に決める。
HardもEasyも同じ点数の参加者は同順位とし、順位の番号は今と同じく同順位の人数だけ次を飛ばす。
時間、不正解数で順位は変えず、誤答ペナルティも設けない。

各問題の比較では、満点に届いたかどうかを先に比べ、次に点数を比べる。
採点の定義が変わらない問題では、満点は点数の最大なので、点数だけを比べるのと同じ結果になる。
定期便の問題は、コンテストの問題と違って採点の定義を固定しない。
配点や採点方式が集計期間の途中で変わっても、満点に届いた参加者を上に置く。

部分点のない問題（一括方式）では、正解が満点、それ以外が点数なしにあたる。
Hard、Easyとも部分点のない回の順位は、今の「両方正解、Hardのみ正解、Easyのみ正解、0完」と一致する。

### 各問題の点数は1つの提出の最高点とする

各問題の点数は、集計期間内の1つの提出で取った最高点とする。
小課題ごとに別の提出で取った点数は合算しない。
ADR 0025は、コンテストの外の提出をグループごとに合算しないと決めており、定期便もこれに合わせる。
定期便の問題は集計期間の途中で採点の定義が変わりうるので、別々の提出のグループの点を足すと、定義の違う点を足すことになる。

点数の比較は、提出の結果に保存した100倍の整数で行う（ADR 0025）。

### 時間と不正解数は、コンテストの数え方に合わせる

判定済み（CE、JE、判定待ちを除く）の提出のうち、初めて満点に届いた提出と、それまでの最高点を上回った提出を、点数を伸ばした提出とする。
それ以外の判定済みの提出を不正解とする。
コンテストの「得点を伸ばした提出」と「誤答」（ADR 0025）と同じ分け方である。

各問題の時間は、最後に点数を伸ばした提出の、公開からの経過時間とする。
この提出は、今の点数に初めて届いた提出にあたる。
不正解数は、その提出より前の不正解を数え、点数を伸ばした提出のない問題ではすべての不正解を数える。
全体の時間は、2問のうち後に今の点数に届いた問題の時間とし、両方とも点数を伸ばした提出がなければ空欄にする。
同順位の中では全体の時間が早い参加者から表示し、両方0点の参加者は最初の提出の時刻順に表示する。

部分点のない問題では、点数を伸ばした提出は初正解だけになるので、時間と不正解数は今の規則と一致する。

### 欄に点数を出し、満点にはチェックマークを並べる

部分点の問題の欄には、点数を表示する。
満点はチェックマークと強調色の点数を横に並べ、満点に届かない点数は通常の色で点数だけを出す。
0点は、今の未正解と同じく「—」とする。
満点を強調色で、部分点を通常の色で示すのは、コンテストの順位表（ADR 0025）と同じである。
点数の書き方もコンテストに合わせ、端数がなければ整数で、あれば小数第2位まで出す。

部分点のない問題は点数を持たないので、今と同じくチェックマークだけを出す。

順位表のAPIは、各問題の結果に`score`（1つの提出の最高点を100倍した整数）を足し、部分点のない問題では`null`とする。
各問題の`timeMs`は、初正解の時刻から、最後に点数を伸ばした時刻に変える。
部分点のない問題では、どちらも同じ時刻である。

## 代替案

- **小課題ごとの最高点を合算する（コンテストと同じ）**：小課題ごとに別の解法を書いた参加者が、解法を1つにまとめ直さずに済む。
  しかし、定期便の問題は採点の定義を固定しないので、定義の違う点を足しうる。
  ADR 0025の決定とも食い違うので採らなかった。
- **HardとEasyの点数の合計で決める**：今の順位はHardの正解をEasyの正解より上に置いている。
  合計で決めると、Easyだけ満点の参加者が、Hardで部分点を取った参加者より上に来ることがあり、この順が崩れるので採らなかった。
- **順位だけ点数で決め、表には点数を出さない**：今の表と見た目が変わらない。
  しかし、同じ「—」の参加者の間で順位が違う理由を、表から読み取れなくなるので採らなかった。

## 影響

- 部分点の問題を含まない回は、順位、時間、不正解数とも今と変わらない。
- 順位表のAPIの各問題の結果に`score`が増える。
  Webは`score`のない応答を`null`として扱い、古いWebは`score`を読み捨てるので、APIとWebはどちらを先に配布してもよい。
- 定期便の順位表のページにある「順位の決まり方」を、点数で順位を決める説明に書き換える。
