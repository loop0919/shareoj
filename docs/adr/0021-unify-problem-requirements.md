# ADR 0021: 公開・コンテスト・定期便に、同じ内容の条件を求める

- 状態：Accepted（内容の条件と保存時に確かめる範囲は[ADR 0025](0025-score-partially-with-test-groups.md)で一部変更）
- 決定日：2026-10-18
- 一部変更：[ADR 0013](0013-assess-problem-readiness.md)の、出し先ごとに内容の条件を変える決定

## 背景

ADR 0013では、問題の内容の条件を出し先ごとに段階的に定めていた。
公開はタイトル・本文・難易度（判定用コードを使う問題では、ジャッジで使える言語の判定用コード）、コンテストはそれに加えてテストケース1件以上、定期便はさらに解説を求めていた。

段階があるため、テストケースのない問題を公開すると、誰も提出できない問題が一覧に並んだ。
解説のない問題は、公開できてもコンテストや定期便には出せず、作者は出し先ごとに足りない項目を確かめる必要があった。
投稿ページと応募ページを並べたことで（[ADR 0020](0020-post-and-apply-on-dedicated-pages.md)）、出し先によって条件が違うことが目立つようになった。

## 決定

### 内容の条件を1つにする

公開、公開予約、コンテストへの登録、定期便への応募に、同じ内容の条件を求める。
条件は、これまでの定期便の条件と同じとする。

- タイトルと本文がある
- 作成者が設定した難易度がある
- テストケースが1件以上ある
- 解説がある
- スペシャルジャッジとインタラクティブでは、ジャッジで使える言語の判定用コードがある

内容の判定はサーバーの1つの関数にまとめ、すべての出し先がこれを使う。
出し先ごとに違うのは、問題の状態による制限（公開中、公開歴、公開予約、コンテストへの登録、定期便への応募、応募件数の上限）だけになる。
画面は、出せない理由のコードをこれまでどおり表示し、条件を持たない。

### 公開中の問題の保存にも同じ条件を求める

公開中の問題を保存すると公開内容がすぐに変わるため、保存時にも同じ条件を確かめる。
これはADR 0013で難易度を必須にしたときと同じ扱いである。

## 代替案

公開だけ緩い条件のまま残す案は、提出できない問題や解説のない問題が公開され続けるため採用しない。
条件を満たさない公開中の問題を非公開に戻す案は、閲覧者と提出者に影響が大きいため採用しない。

## 影響

- テストケースや解説のない問題は、公開、公開予約、コンテストへの登録ができなくなる。投稿ページでは理由を添えて選べなくなる。
- すでに公開中でテストケースや解説のない問題は、公開されたまま残る。公開内容を更新するときに、足りない項目の追加が必要になる。
- 公開予約済みの問題は、予約した時点の内容を予定どおり公開する。予約を更新するときには新しい条件を確かめる。
- 開始前のコンテストに条件を満たさない問題が登録されている場合、そのコンテストは問題を直すまで保存し直せない。コンテストの終了時の公開は、これまでどおり行われる。
- 準備状況は「準備中」の✅と×の2つで、どの出し先にも出せるかどうかを示すだけになる。
