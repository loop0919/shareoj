# 問い合わせメールのDiscord通知

プライバシーポリシーの問い合わせ窓口（Gmail）に届いたメールを、Discordのウェブフックで知らせます。
Gmailのアカウント上でGoogle Apps Scriptを5分ごとに実行し、受信トレイに新しいメールがあれば件数とGmailへのリンクを送ります。
コードは[scripts/gmail-discord/](../scripts/gmail-discord/)にあります。

## 送る内容

既定では、件数とGmailへのリンクだけを送ります。
権限は`gmail.metadata`に絞っているため、スクリプトはメールの本文を読めません。

`Code.js`の`INCLUDE_DETAILS`を`true`にすると、メールごとに件名と差出人も送ります。
問い合わせ者のメールアドレスや氏名がDiscordに残るため、有効にする場合はプライバシーポリシーの第7条に、Discordに保存することを書き足してください。
どちらの場合も、本文に`@everyone`などが含まれていてもメンションにはなりません。

## 設定

1. Discordで、自分だけが見られるチャンネルを作ります。チャンネルの設定の「連携サービス」から「ウェブフック」を作成し、URLをコピーします。
2. 問い合わせ用のGmailアカウントでログインした状態で、[Google Apps Script](https://script.google.com/)の新しいプロジェクトを作成します。
3. 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにします。エディタの`appsscript.json`と`コード.gs`の中身を、このリポジトリの`appsscript.json`と`Code.js`の内容に置き換えて保存します。
4. 「プロジェクトの設定」の「スクリプト プロパティ」に、プロパティ`DISCORD_WEBHOOK_URL`を追加し、値に手順1のURLを入れます。URLをコードやGitに書かないでください。
5. エディタで関数`testWebhook`を実行します。初回は権限の確認が出るので、Gmailのメタデータの閲覧、外部サービスへの接続、トリガーの管理を許可します。自分で作ったスクリプトのため「Googleで確認されていません」と表示された場合は、「詳細」から進みます。Discordに「ShareOJのメール通知を設定しました。」と届けば成功です。
6. 関数`setup`を実行します。5分ごとのトリガーを作成し、この時点で受信トレイにあるメールを通知済みとして記録します。過去のメールはまとめて送りません。

`setup`を再実行しても、トリガーは重複しません。

## 止めるとき・URLが漏れたとき

通知を止めるときは、Apps Scriptの「トリガー」画面で`notifyNewMail`のトリガーを削除します。
ウェブフックのURLが漏れた場合は、Discordでそのウェブフックを削除して作り直し、スクリプト プロパティの値を差し替えます。

送信に失敗した回は、その回のメールを未通知のまま残し、次の実行で送り直します。
失敗が続くと、Apps Scriptがエラーの概要をGmailアカウントにメールで送ります。
