## 作問画面を開く {#start}

![ヘッダーの作成メニュー。①作成、②新規問題](/images/docs/create-problem.png)

ログインしてから、ヘッダーの①「作成」で②「新規問題」を選びます。

![作問画面。サイドバーの①問題文から⑥問題管理までと、⑦保存](/images/docs/problem-editor.png)

サイドバーの①〜⑥で編集する項目を切り替えます。

| 項目 | 設定する内容 |
| --- | --- |
| ①問題文 | タイトル、難易度、実行時間制限、メモリ制限、タグ、本文 |
| ②テストケース | 採点に使う入力と期待される出力 |
| ③生成・検証・判定 | テストケースを作るコード、入力の検証、判定方法 |
| ④採点 | 一括採点か[部分点採点](#scoring)か |
| ⑤解説 | 問題ページの「解説」タブに表示する文章 |
| ⑥問題管理 | 公開できるかの確認、テスターの招待、リジャッジ、問題の削除 |

## 問題文と設定 {#statement}

本文と解説はMarkdownで書きます（[Markdown と数式の書き方](/docs/markdown)）。
難易度は[難易度の目安](/docs/difficulty)を参考に選んでください。

| 項目 | 範囲 |
| --- | --- |
| タイトル | 120文字まで |
| 本文、解説 | それぞれ100,000文字まで |
| 実行時間制限 | 100〜5,000ミリ秒（100ミリ秒単位） |
| メモリ制限 | 64〜512 MiB |
| タグ | 5個まで |

## テストケース {#tests}

![テストケースの画面。①ファイルから一括追加、②サンプルケースにする、③サンプルを問題文に追加、④並べ替え](/images/docs/problem-tests.png)

| 番号 | できること |
| --- | --- |
| ① | 手元のファイルをまとめて登録します。 |
| ② | そのケースをサンプルケースにします。解く人の「サンプル検証」で使います。 |
| ③ | サンプルケースの入出力を本文に書き足します。もう一度押すと、書き足した部分を今のテストケースの内容に書き換えます。 |
| ④ | ドラッグしてケースの順番を変えます。 |

採点、サンプル検証、③で書き足すサンプルは、この順番に従います。
テストケースをコードで作る方法は、[入出力生成と入力検証の使い方](/docs/generator)で説明しています。

## 部分点 {#scoring}

![採点の画面。①採点方式、②集計コードで採点する、③グループの名前と配点、④グループを追加](/images/docs/problem-scoring.png)

「採点」の①で採点方式を選びます。

| 採点方式 | 得点 |
| --- | --- |
| 一括採点 | すべてのケースが:AC:なら満点です。部分点はありません。 |
| 部分点採点 | ケースをグループに分け、グループの得点の合計を提出の得点にします。 |

部分点採点は、次の手順で設定します。

1. ④でグループを足します。
2. ③でグループの名前と配点を決めます。
3. 「テストケース」の「所属するグループ」で、各ケースが入るグループを選びます。

- グループの得点は、属するケースがすべて:AC:なら配点、そうでなければ0点です。
- 満点は配点の合計で、1〜1,000,000点にします。
- 1つのケースを複数のグループに入れられます。
- ②「集計コードで採点する」をオンにすると、[集計コード](/docs/checkers#aggregator)がグループの得点を決めます。
- コンテストに入れた問題は、開始後に採点方式とグループの設定を変えられません。

## 保存する {#save}

| 問題の状態 | 保存のしかた |
| --- | --- |
| 公開も公開予約もしておらず、コンテストにも登録していない | 編集すると自動で保存します。 |
| 公開中、公開予約中、コンテストに登録済み | 「保存」（[作問画面](#start)の⑦）を押すと、その時点の内容を反映します。 |

- 保存しても、問題は公開されません。
- 保存した問題は、マイページの「自分の問題」から開けます。
- 新しい問題を初めて保存するときに、作成枠を1件使います。作成枠は最大20件で、2時間ごとに1件ずつ回復します。

## 公開できるかを確かめる {#readiness}

![問題管理の状態。①判定の結果、②足りない項目を開くボタン](/images/docs/problem-status.png)

「問題管理」の①「状態」に、保存済みの内容で公開やコンテスト、定期便に出せるかを表示します。
足りない項目は、②のボタンから開いて直せます。

公開、コンテスト、定期便のどれに出すときも、同じものが必要です。

- タイトルと本文
- 難易度
- テストケース1件以上
- 解説
- スペシャルジャッジかインタラクティブでは、ジャッジで使える言語の判定コード
- 部分点採点では、グループ1つ以上、各グループにケース1件以上、サンプル以外のすべてのケースの所属。集計コードで採点するなら、ジャッジで使える言語の集計コード

公開中や公開予約中の問題、結果が確定する前のコンテストに入っている問題は、これらがそろっていないと保存できません。

## 公開する {#publish}

![エディタの「公開・応募」で開く、①問題を投稿と②定期便に応募](/images/docs/problem-publish-choice.png)

保存した問題は、エディタ上部の「公開・応募」から出せます。
①「問題を投稿」で投稿ページを、②「定期便に応募」で[応募ページ](/docs/featured-apply#apply)を開きます。
足りない項目があるときは、選べない理由を表示します。

![投稿ページの①問題、②公開のタイミング、③投稿する](/images/docs/problem-post.png)

投稿ページでは、次の手順で公開します。

1. ①で問題を選びます。
2. ②で公開のタイミングを選びます。
3. ③「投稿する」を押します。

| 公開のタイミング | 動き |
| --- | --- |
| 今すぐ | すぐに公開します。 |
| 日時を指定 | 保存済みの内容を、指定した日時に公開します。 |

- 予約したあとに内容を直すには、編集画面で「保存」を押します。
- 公開日時の変更は投稿ページの「予約を更新」で、取り消しは「予約を取り消す」で行います。
- コンテストに登録した問題は投稿できません。コンテストの終了後に自動で公開されます。
- 定期便に応募中の問題を今すぐ公開すると、応募は取り下げになります。応募中の問題は予約できません。
- 公開する前でも、作者とテスターは問題ページから提出できます。

## 公開したあと {#after-publish}

公開中の問題を編集して「保存」すると、すぐに公開内容に反映します。
受け付け済みの提出の結果は変わらないので、新しい内容で採点し直すには[リジャッジ](#rejudge)してください。

![問題管理の①非公開に戻すと②問題を削除](/images/docs/problem-unpublish.png)

「問題管理」の①で非公開に戻し、②で問題を削除できます。

- 一度公開した問題は、非公開に戻しても定期便には応募できません。
- コンテストに登録した問題は削除できません。

## リジャッジする {#rejudge}

テストケースや判定方法を直したあと、受け付け済みの提出を保存済みの内容で採点し直せます。
先に「保存」してください。

![問題管理の①すべてリジャッジ](/images/docs/problem-rejudge.png)

「問題管理」の①「すべてリジャッジ」は、この問題へのすべての提出が対象です。

![すべての提出の一覧。①提出のチェックボックス、②リジャッジ](/images/docs/rejudge-list.png)

「すべての提出」「自分の提出」では、①で選んだ提出だけを②でリジャッジできます。
提出結果の画面の「この提出をリジャッジ」は、その提出だけが対象です。

採点中の提出、サンプル検証、現在使えない言語の提出は対象外です。

## テスターを招く {#testers}

![問題管理のテスターリンク。①リンクを発行、②リンクをコピー](/images/docs/problem-testers.png)

1. 「問題管理」の①で招待リンクを作ります。
2. ②でリンクをコピーして、招待する人に渡します。

リンクを開いた人が「許可する」を押すと、その問題のテスターになります。

| できること | 作者 | テスター |
| --- | --- | --- |
| 非公開の問題文、解説、テストケースの閲覧と、提出 | ○ | ○ |
| 編集、削除、リジャッジ、非公開に戻す操作 | ○ | ○ |
| 自分のコンテストへの登録 | ○ | ○ |
| 公開、公開予約、定期便への応募 | ○ | × |

公開したコンテストに入った問題は、そのコンテストの作成者も結果が確定するまで編集できます（[共同作成者](/docs/hosting-contests#setters)）。

## 解説とユーザー解説 {#editorials}

- 作問画面の「解説」に書いた文章は、問題ページの「解説」タブに表示します。
- ほかのユーザーが記事の「解説する問題」にこの問題を指定すると、その記事が問題ページの「ユーザー解説」に並びます。
- ユーザー解説を付けられるのは、解説が公開されている問題だけです。
