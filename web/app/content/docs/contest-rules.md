参加登録、チームの作り方、質問のしかたは[コンテストに参加する](/docs/contest-participation)にまとめています。

## 公式順位に入る提出 {#official}

公式順位に入るのは、次の両方を満たす提出です。

- コンテスト内の問題ページから提出した。
- 開催時間中に受け付けられた。判定が終了後に出ても入ります。

サンプル検証と、通常の問題ページからの提出は入りません。

## 得点と順位 {#scoring}

| 項目 | 決まり方 |
| --- | --- |
| 問題の得点 | 正解（:AC:）すると、その問題の配点を獲得します。 |
| 部分点のある問題の得点 | 小課題などのグループごとに全提出の最高点をとり、その合計を得点とします。 |
| 順位 | 合計得点の高い順です。 |
| 同点のとき | 開始から、最後に得点を伸ばした提出までの時間に、[誤答ペナルティ](#penalty)を足します。この時間が短い方が上位で、これも同じなら同順位です。 |

チーム戦ではメンバー全員の提出をまとめて、1人分と同じ決まりで計算します。
個人参加の人は、チームと同じ順位表に1人で並びます。

## 誤答ペナルティ {#penalty}

得点した問題ごとに、誤答の回数だけペナルティ時間を足します。
1回あたりのペナルティ時間はコンテストのページに表示します。

| 扱い | 対象 |
| --- | --- |
| 誤答として数える | :WA:、:RE:、:TLE:、:MLE:、:OLE: |
| 数えない | :CE:、:JE:、判定待ちの提出 |
| 数えない | 得点していない問題の誤答 |

数える誤答の範囲は、問題の採点方式で違います。

| 問題 | 数える範囲 |
| --- | --- |
| 部分点のない問題 | 初めて正解する前の誤答 |
| 部分点のある問題 | 最後に得点を伸ばした提出より前の、得点を伸ばさなかった提出 |

たとえば、次の場合に順位の比較に使う時間は55分です。

- 最後に得点を伸ばした提出が開始から45分後
- 正解する前の誤答が合計2回
- ペナルティが1回5分

## 順位表の凍結 {#freeze}

コンテストによっては、終了前の一定時間、順位表を凍結します。

- 凍結後の提出は順位表に「?2」のように件数だけを表示します。
- 凍結後の提出の結果は、作成者が公開するまで、本人とチームメイト、スタッフだけが見られます。

## 問題と提出の公開範囲 {#visibility}

| 時期 | 問題 | ほかの人の提出 |
| --- | --- | --- |
| 開始前 | 公開しません。 | 公開しません。 |
| 開催中 | 全員に公開します。 | チーム戦のチームメイトの提出だけを見られます。 |
| 終了後 | 解説とともに、通常の問題ページにも公開します。 | 開催時間中の提出と練習提出を、誰でも見られます。 |

- スタッフ（コンテストの作成者と、問題の作者とテスター）は、開催中もすべての提出を見られます。
- 開始前の問題を見られるのは、コンテストの作成者と、その問題の作者とテスターです。
- 順位表を凍結したコンテストでは、凍結後の提出の結果は、終了後も作成者が公開するまで公開しません。
- 開始前のテスト提出とサンプル検証は、終了後も公開しません。
