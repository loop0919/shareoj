## 参加登録する {#join}

1. ログインして、コンテストのページを開きます。
2. 「参加する」を押します。

- 登録は終了時刻まで受け付けます。
- 開催中に提出するには、参加登録が必要です。
- 登録すると、提出していなくても0点で順位表に載ります。
- 終了後は登録できませんが、練習として提出できます。

## チームで参加する {#team}

![チーム戦のコンテストの参加欄。①会場の合言葉、②個人参加、③チーム参加](/images/docs/contest-join.png)

チーム戦のコンテストでは参加のしかたを選びます。

| 参加のしかた | 操作 |
| --- | --- |
| 1人で参加する | ②「個人参加」を押す |
| チームを作る | ③「チーム参加」を押し、チームを作って参加コードをメンバーに伝える |
| チームに入る | ③「チーム参加」を押し、メンバーから聞いた参加コードを入れる |

チームの変更は開始前に済ませてください。
個人参加からチームへの切り替えと、チームを抜ける操作は、開始前だけできます。

## 会場で参加する {#onsite}

オンサイト区分があるコンテストでは、参加欄に①「会場の合言葉」が出ます。

| 参加の区分 | 操作 |
| --- | --- |
| オンサイト参加 | 会場で配られた合言葉を①に入れて参加する |
| オープン参加 | ①を空のまま参加する |

## 質問する {#clarifications}

開催中は問題について質問できます。

1. コンテストメニューの「質問」を開きます。
2. 対象の問題を選び、質問を書いて送ります。

- 回答はベルに届きます。
- 質問は、担当者が全体公開するまでチームメイトには表示しません。
- 全体公開されると、質問と回答、質問した人の名前を、ログインした全員が見られます。個人情報は書かないでください。
- 質問を受け付けるのは終了時刻までです。

## 自分の提出を見る {#my-submissions}

- コンテストメニューの「自分の提出」に、全問題の提出が並びます。
- チーム戦では「チームの提出」になり、チームメイトの提出も並びます。
- ほかの人の提出は終了後に見られます。

順位の決まり方と、問題や提出が公開される時期は、[コンテストのルール](/docs/contest-rules)にまとめています。
