## 出題の日時 {#schedule}

定期便は、毎週月曜と木曜の23時（日本時間）に、Easy（Lv.1〜4）とHard（Lv.5〜10）を1問ずつ出題します。
出題する問題は、出題時刻に自動で選びます。

- 応募された未公開の問題があれば、新作として出題します。
- 新作がなければ、公開済みの問題から同じ難易度帯の問題を復刻として選びます。過去30日に出題していない問題を優先します。
- 新作も復刻もなければ、その枠は欠番になります。

次回予告には作問者、テスター、難易度と、新作か復刻かを表示します。
問題のタイトルは出題まで公開しません。

## 解いて順位表に載る {#solve}

出題した問題は、通常の問題と同じように提出できます。
新作の解説とほかの人の提出は、翌日の22時に公開します。
復刻の問題では、はじめから公開しています。

出題から翌日22時までに受け付けた提出で、順位表を作ります。
サンプル検証、コンテストからの提出、その回の作問者とテスターは対象外です。

順位は、どの問題に正解したかで決めます。

1. EasyとHardの両方に正解
2. Hardだけに正解
3. Easyだけに正解
4. 正解なし

正解した問題が同じ人は同順位で、その状態になった提出が早い人から順に表示します。
得点と誤答ペナルティはありません。

## 新作を応募する {#apply}

![応募ページの①問題、②希望、③入る見込みの回、④応募する](/images/docs/featured-apply.png)

定期便のページの「新作を応募」か、エディタ上部の「公開・応募」から「定期便に応募」を選ぶと、応募ページを開きます。
①で問題、②で希望を選ぶと、右の予定表の③に、その問題が入る見込みの回を表示します。
④「応募する」を押すと応募できます。
応募は作者ごとに3件までです。

これからの出題は、[定期便の予定](/featured/schedule)で8回先まで確かめられます。
次回は予告と同じで確定、2回目以降は今の応募をもとにした見込みで、取り下げや新しい応募で入れ替わります。
応募すると、予定表に作者名が載ります。問題名は出題まで載りません。

応募できるのは、自分が作った問題のうち、次の条件をすべて満たすものです。
足りない項目は「問題管理」で確かめられます（[公開できるかを確かめる](/docs/authoring#readiness)）。

- 一度も公開したことがなく、公開予約もコンテストへの登録もしていない。
- タイトル、本文、難易度、テストケース1件以上、解説がそろっている。スペシャルジャッジかインタラクティブでは、判定コードも必要です。

各枠では、「早めに出したい」を2回、「ゆっくりで良い」を1回の順で選ぶことを基本に、それぞれ応募の早い問題から選びます。
選ばれた問題は、出題時刻に保存されている内容で公開します。
出題時刻に条件を満たしていない応募は選ばず、応募中のまま残します。

応募は、マイページの「自分の問題」から取り下げられます。
問題を公開した場合も、応募は取り下げられます。
応募中の問題は、取り下げるまでコンテストに登録できません。
