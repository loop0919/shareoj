新作を出題したい方は[定期便に応募する](/docs/featured-apply)をご覧ください。

## 出題の日時 {#schedule}

毎週月曜と木曜の22:00 (JST)に、EasyとHardを1問ずつ出題します。

| 枠 | 難易度 |
| --- | --- |
| Easy | Lv.1〜4 |
| Hard | Lv.5〜10 |

出題する問題には、新作と復刻があります。

| 種類 | 内容 |
| --- | --- |
| 新作 | 作問者が応募した、未公開の問題 |
| 復刻 | 公開済みの問題。新作の応募がない枠で出題します。 |

次回予告には、作問者、テスター、難易度、新作か復刻かを表示します。
問題のタイトルは出題まで公開しません。

## 解く {#solve}

出題した問題は通常の問題と同じように提出できます。
解説とほかの人の提出が公開される時期は、新作と復刻で違います。

| 種類 | 解説とほかの人の提出 |
| --- | --- |
| 新作 | 出題の翌日22時に公開します。 |
| 復刻 | はじめから公開しています。 |

## 順位表 {#standings}

出題から翌日22時までに受け付けた提出で、順位表を作ります。
サンプル検証、コンテストからの提出、その回の作問者とテスターは対象外です。

- Hardの点数が高い順に並べます。
- Hardが同点なら、Easyの点数が高い順に並べます。
- HardもEasyも同じ点数なら同順位です。同順位の中ではその点数に先に届いた人から表示します。
- 各問題の点数は1回の提出で取った最高点です。別々の提出の点数は合算しません。
- 誤答ペナルティはありません。

部分点のない問題は正解か不正解かだけで比べます。
2問とも部分点がない回の順位は、次の順です。

1. EasyとHardの両方に正解
2. Hardだけに正解
3. Easyだけに正解
4. 正解なし
