## 出題する問題を用意する {#problems}

出題できるのは、自分が作った問題か、テスターとして参加している問題です。
次の条件をすべて満たす必要があります。

- 公開も公開予約もしていない。
- 定期便に応募していない。
- ほかのコンテストに登録していない。終了したコンテストの問題も登録できません。
- 公開に必要な項目がそろっている（[公開できるかを確かめる](/docs/authoring#readiness)）。

## コンテストを作る {#create}

![ヘッダーの作成メニュー。①作成、②新規コンテスト](/images/docs/create-contest.png)

ヘッダーの①「作成」で②「新規コンテスト」を選ぶと、編集画面が開きます。

![コンテストの編集画面。サイドバーの①タイトル・説明から⑤コンテスト管理までと、⑥保存、⑦公開](/images/docs/contest-editor.png)

1. サイドバーの①〜④で、設定を入力します。
2. ⑥「保存」を押します。編集画面は自動では保存しません。

| 項目 | 設定する内容 | 範囲 |
| --- | --- | --- |
| ②問題・配点 | 出題する問題、出題順、配点 | 1〜100問、配点は1〜1,000,000点 |
| ③期間・ペナルティ | 開始日時、コンテスト時間、誤答ペナルティ、[順位表の凍結](/docs/contest-rules#freeze) | ペナルティは0〜1440分 |
| ④参加形式 | 個人戦かチーム戦か、1チームの人数の上限、オンサイト区分と会場の合言葉 | 人数の上限は2〜50人 |

- 開始日時はJSTで入力します。
- [部分点](/docs/authoring#scoring)の問題は、問題の満点が配点になります。
- チーム戦でも、参加者はチームを作らずに個人で参加できます。
- 初めて保存すると、作成者だけが見られる下書きになり、作成枠を1件使います。

## 公開する {#publish}

[編集画面](#create)の⑦「公開」を押すと、次の条件を確かめてから公開します。
足りない項目は一覧で表示します。

- タイトルがある。
- 開始日時が現在より後である。
- 問題が1問以上あり、どの問題も[出題の条件](#problems)を満たしている。

公開すると、コンテスト一覧に載り、参加登録が始まります。
問題名と問題文は、開始時刻に公開されます。

## 開始前と開始後の変更 {#changes}

| 時期 | 変えられるもの |
| --- | --- |
| 開始前 | すべての設定。公開したあとでも変えられます。 |
| 開始後 | 問題の内容、会場の合言葉、チーム名、参加者のオンサイト区分 |

- 参加登録があると、個人戦とチーム戦は切り替えられません。
- 開始後は、問題の組み合わせ、配点、開催期間、ペナルティ、凍結、参加形式を変えられません。
- 問題の内容は作問画面で「保存」すると、そのあとに受け付けた提出から反映されます。受け付け済みの提出の結果を直すには、[リジャッジ](/docs/authoring#rejudge)してください。
- 会場の合言葉、チーム名、オンサイト区分は、コンテストのページの「参加者の管理」で変えます。
- 下書きは「下書きを削除」で削除できます。公開したコンテストは削除も中止もできません。

## 共同作成者 {#setters}

![コンテスト管理の共同作成者。①リンクをコピー、②リンクを作り直す、③外す](/images/docs/contest-setters.png)

コンテストは複数人で作れます。
下書きを作った人を**オーナー**、招待リンクから加わった人を**共同作成者**と呼びます。

1. 「コンテスト管理」の「リンクを発行」を押します。
2. ①でリンクをコピーして、招待する人に渡します。

- 共同作成者は、設定の編集、問題の追加、公開、[質問への回答](#clarifications)ができます。
- 共同作成者を③で外せるのは、オーナーだけです。
- ②でリンクを作り直すと、古いリンクは使えなくなります。
- 公開したコンテストの問題は、結果が確定するまで、オーナーと共同作成者の全員が編集とリジャッジをできます。

## スタッフ {#staff}

オーナーと共同作成者、コンテストの問題の作者とテスターを、まとめて**スタッフ**と呼びます。

- スタッフは参加登録できません。公式順位にも載りません。
- スタッフは開催中もすべての提出を見られます。
- テスターは問題ごとに招待します（[テスターを招く](/docs/authoring#testers)）。
- 解説は各問題の作問画面の「解説」に書きます。終了時刻に公開されます。

## 質問に回答する {#clarifications}

参加者が出した質問（[質問する](/docs/contest-participation#clarifications)）は、コンテストメニューの「質問」に並びます。

| 担当 | 回答と全体公開ができる質問 |
| --- | --- |
| オーナーと共同作成者 | すべての質問 |
| 問題の作者とテスター | 担当している問題への質問 |

- 全体公開する前の質問は、質問した本人と、上の表の担当者だけが見られます。
- 全体公開すると、質問と回答、質問した人の名前を、ログインした全員が見られます。
- 全体公開は取り消せません。
- 質問の受付は終了時刻までですが、終了後も回答できます。

## 終了したあと {#after}

- 終了時刻に、各問題と解説が自動で公開されます。
- 順位表を凍結しなかったコンテストは、終了時刻に結果が確定します。
- 凍結したコンテストは、順位表の「結果を公開」を押すと結果が確定します。参加者の判定待ちの提出が残っている間は押せません。
- 公開された問題は非公開に戻せますが、削除とほかのコンテストへの登録はできません。
