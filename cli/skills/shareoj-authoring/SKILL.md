# ShareOJで作問する

最初に `shareoj guide` を実行し、インストール済みCLIに同梱された作問手順を読む。
仕様やコマンドを記憶から補わず、必要なオプションは `shareoj <command> --help` で確認する。
CLIが見つからない場合は https://github.com/loop0919/shareoj/tree/main/cli のインストール手順を案内する。
CLIが `guide` に対応していない場合は、更新が必要なことを伝える。

ユーザーの依頼に応じて、新しい問題の作成、既存の下書きの編集、テスターとしての検証を進める。
作成だけを頼まれた場合はローカルに問題を用意し、ShareOJへの保存まで依頼されていれば `push` を実行する。
認証が必要なら、ユーザー自身にログインしてもらう。
秘密情報を会話や問題ファイルに書き出さない。

完了時は問題ディレクトリ、実際に行った検証、未検証の項目、保存の有無を短く報告する。
保存できた場合はCLIが返した問題IDと版番号も伝える。
